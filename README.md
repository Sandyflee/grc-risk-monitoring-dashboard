# GRC Risk Monitoring Dashboard and Management Reporting

## Project Overview

This project demonstrates the application of Governance, Risk and Compliance (GRC) principles in monitoring organisational security controls, identifying emerging risks and preparing management reports.

The assessment uses a fictional organisation, Northbridge Services, and three months of operational data (January–March).

The objective was to analyse control performance, identify threshold breaches, assess risks and recommend accountable corrective actions.

## Project Objectives

- Develop an Excel-based risk monitoring dashboard.
- Calculate and classify five key risk and control indicators.
- Analyse monthly control performance trends.
- Identify and assess priority operational and cybersecurity risks.
- Develop a risk register with likelihood and impact scoring.
- Prepare a risk treatment and assurance plan.
- Communicate findings and recommendations through a management report.

## Key Performance Indicators

The dashboard monitors:

1. Monitoring Coverage
2. Timely Critical-Alert Review
3. Restore-Test Success
4. Overdue High-Risk Action Rate
5. Confirmed Unauthorised File Changes

## March Findings

The March reporting period identified the following concerns:

| Indicator | March Result | Status |
|---|---:|---|
| Monitoring Coverage | 90.0% | Red |
| Timely Alert Review | 70.0% | Red |
| Restore-Test Success | 80.0% | Red |
| Overdue Action Rate | 40.0% | Red |
| Unauthorised Changes | 5 | Red |

### Key Observations

- 12 eligible endpoints were not actively monitored.
- Only 28 out of 40 critical alerts were reviewed within 24 hours.
- Two out of ten restoration tests were unsuccessful.
- Six out of fifteen high-risk actions were overdue.
- Five confirmed unauthorised file changes were recorded.

## Risk Assessment

Four priority risks were documented:

- Endpoint monitoring blind spots.
- Delayed critical-alert review.
- Backup and restoration failures.
- Overdue risk treatment actions.

Risks were assessed using a 5 × 5 likelihood and impact matrix.

## Recommended Actions

- Improve endpoint monitoring coverage.
- Strengthen critical-alert review and escalation procedures.
- Investigate failed restoration tests and verify successful recovery.
- Improve ownership, tracking and escalation of overdue risk treatments.
